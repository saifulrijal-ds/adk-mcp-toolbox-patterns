## Project Overview

An ADK (Google Agent Development Kit) SQL agent that connects to a `collection_db` database via **MCP Toolbox**. The agent answers collection operations questions (field visits, payments, DPD aging, PTP, branch performance) for an Indonesian multifinance context. Data scope is January–March 2025 only.

## Commands

This project uses `uv` for dependency management (Python 3.13).

```bash
# Install dependencies
uv sync

# Run the ADK web UI (primary development interface)
uv run adk web

# Run the ADK CLI
uv run adk run collection_analysis_agent

# Run the ADK API server
uv run adk api_server
```

> The `adk web` command auto-discovers agents by scanning for `agent.py` files in subdirectories. The agent module must expose a `root_agent` variable.

## Architecture

```
adk-sql-agent/
├── collection_analysis_agent/   # ADK agent package
│   ├── agent.py                 # root_agent definition (LlmAgent + BuiltInPlanner)
│   ├── prompts.py               # BASE_SYSTEM_PROMPT (5-pattern structured prompt)
│   ├── __init__.py              # re-exports agent module (required by ADK discovery)
│   └── .env                    # GOOGLE_API_KEY (not committed)
└── main.py                      # placeholder entrypoint (not used by ADK)
```

### How the agent works

- `agent.py` creates a `root_agent` using `google.adk.agents.llm_agent.Agent` backed by Gemini.
- `BuiltInPlanner` with `ThinkingLevel.LOW` is set for lightweight multi-step reasoning before tool calls.
- The system prompt (`prompts.py`) instructs the agent to use MCP Toolbox tools: `load_skill()`, `read_skill_reference()`, `write_and_execute_sql`, and `execute_query` — these are provided at runtime by the Toolbox server, not defined in this repo.
- MCP Toolbox connection is configured via the `.env` file or environment variables; the `google-adk[toolbox]` extra handles the Toolbox client.
- `.adk/artifacts/` stores session trace artifacts generated by `adk web`.

### Key design constraints

- The agent is **read-only**: the system prompt strictly forbids non-SELECT SQL.
- Always call `load_skill()` before writing SQL — the prompt enforces this as step 2 of the workflow.
- Model is `gemini-3.1-flash-lite-preview` with retry config (4 attempts, 2s initial delay).

## Environment

Set in `collection_analysis_agent/.env`:
```
GOOGLE_API_KEY=<your-key>
```

The MCP Toolbox server URL is typically configured separately (e.g., `TOOLBOX_URL` env var or ADK config) when connecting to a live `collection_db`.
